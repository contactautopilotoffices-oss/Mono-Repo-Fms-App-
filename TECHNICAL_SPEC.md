## Cassandra Token Exchange

### Layer 1: REST Token Exchange

- **Endpoint:** `POST {CASSANDRA_API_URL}/auth/session`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
  ```json
  { "token": "<supabase_jwt>" }
  ```
- **Success Response (200):**
  ```json
  { "token": "<cassandra_token>", "expires_at": "<iso_timestamp>" }
  ```
- **Error Response (401):**
  ```json
  { "error": "invalid_token", "message": "Supabase token invalid or expired" }
  ```

### Layer 2: WebSocket Session Start

- **WebSocket URL:** `wss://[host]/ws/cassandra?org_id=[orgId]`
- **Auth:** Cassandra token injected in `session_start` JSON frame
  ```json
  {
    "type": "session_start",
    "token": "<cassandra_token>",
    "org_id": "<orgId>",
    "property_id": "<propertyId>"
  }
  ```

### Token Storage (Mobile)

| Key | Storage | TTL |
|-----|---------|-----|

| `cassandra_expires_at` | SecureStore | — |

## Supabase Query Patterns

### Fetch Organization Membership
```typescript
const { data } = await supabase
  .from('organization_memberships')
  .select(`role, organization(id, name)`)
  .eq('user_id', userId)
  .or('is_active.eq.true,is_active.is.null')
  .limit(1)
  .maybeSingle();
```

### Fetch Property Memberships
```typescript
const { data } = await supabase
  .from('property_memberships')
  .select(`role, property(id, name, code, image_url)`)
  .eq('user_id', userId)
  .or('is_active.eq.true,is_active.is.null');
```

### Org Admin Auto-Inject Properties
```typescript
const ORG_ADMIN_ROLES = ['org_super_admin', 'org_admin', 'owner'];
if (fetchedOrgId && ORG_ADMIN_ROLES.includes(fetchedOrgRole)) {
  const { data: orgPropsData } = await supabase
    .from('properties')
    .select('id, name, code, image_url')
    .eq('organization_id', fetchedOrgId);
}
```

## Auth Flow (Verified)

```
1. User submits email + password
2. supabase.auth.signInWithPassword()
   → Returns { session: { access_token, refresh_token, user } }
3. AuthContext.onAuthStateChange(SIGNED_IN)
   → fetchMembership(userId)
     → Query organization_memberships
     → Query property_memberships
     → Auto-inject org properties for org admins
     → Cache to AsyncStorage (24h TTL)
   → getValidToken() [pre-warm]
     → POST /auth/session { token: supabase_jwt }
     → Cache cassandra_token to SecureStore
4. UI renders with membership data
```

## Error Handling Patterns

| Error | Detection | Recovery |
|-------|-----------|----------|
| `refresh_token_not_found` | `error.message.includes()` | `supabase.auth.signOut()` + clear cache |
| Network failure in `fetchMembership` | `try/catch` | Use stale cached membership if available |
| Cassandra token expired | HTTP 401 | `withTokenRetry()` → re-exchange |
| Table not found | Supabase error code `42P01` | Query NotebookLM for schema |
| Column not found | Supabase error code `42703` | Query NotebookLM for column names |

## Non-Negotiable Rules Summary

1. **Always use `user_photo_url`** — never `avatar_url`
2. **Always include org predicate** — never query without tenant scoping
3. **Always use 24h membership cache** — not 5 minutes
4. **Always pre-warm Cassandra token** — on `SIGNED_IN` event
5. **Always check NotebookLM first** — before asking about schemas
6. **Always run QA tests** — before claiming module complete
